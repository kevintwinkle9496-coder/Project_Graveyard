# 🪦 Project Graveyard

Don't let great engineering projects die at graduation.

Seniors upload their finished projects, faculty verify them, and juniors browse, copy one and build their own version.

## Features

- Login for juniors, seniors and faculty
- Browse projects by department and semester, with uploader details
- Faculty verification before a project goes live
- Copy a project to make your own version
- Visit tickets to see the physical project at college
- Points for seniors: **+50** verified upload, **+10** per visit, **+20** per copy
- Shareable profile with score, and Ripper, the AI helper

## Run locally

1. Install [Python 3](https://www.python.org/downloads/)
2. Windows: double-click `start.bat` (or run `python server.py`)
3. Open http://localhost:8000
